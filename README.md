 🎓 Student Performance Prediction System

A Machine Learning-based classification system that predicts student academic performance using demographic, educational, family, and coaching-related attributes.

The project follows an end-to-end Machine Learning workflow, including data cleaning, exploratory data analysis, preprocessing, model comparison, hyperparameter tuning, model evaluation, model serialization, and Streamlit application development.


 📌 Project Overview

Student performance can be influenced by various academic, demographic, educational, and family-related factors.

This project uses Machine Learning classification algorithms to predict student performance into four categories:

- Average
- Good
- Vg (Very Good)
- Excellent

Multiple classification models were trained and compared to identify the best-performing model for the dataset.


🎯 Objectives

- Analyze student performance data.
- Perform data cleaning and preprocessing.
- Identify patterns and relationships in the dataset.
- Handle categorical features using appropriate encoding techniques.
- Train multiple Machine Learning classification models.
- Compare model performance using standard evaluation metrics.
- Perform hyperparameter tuning on the selected model.
- Save the trained model using Joblib.
- Develop an interactive Streamlit application for prediction.



📊 Dataset

The dataset contains information about students who qualified for a medical entrance examination.

### Dataset Information

- **Original records:** 666
- **Duplicate records removed:** 44
- **Final records:** 622
- **Features:** 11
- **Target variable:** Performance

### Features Used

- Gender
- Caste
- Coaching
- Class X Education
- Class XII Education
- Medium of Education
- Class X Percentage
- Class XII Percentage
- Father's Occupation
- Mother's Occupation
